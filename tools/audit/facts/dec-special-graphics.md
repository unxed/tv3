# DEC Special Graphics character set

The characters that a VT100-compatible terminal shows for the bytes 0x60..0x7E after `ESC ( 0` (designate the DEC
Special Graphics set to G0), as Unicode code points, in the order of the bytes.

Sources: the VT100 User Guide, table 3-9 (https://vt100.net/docs/vt100-ug/table3-9.html); the Unicode mapping of the
set (https://en.wikipedia.org/wiki/DEC_Special_Graphics).
